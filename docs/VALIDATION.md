# 平台验收与有限结论

本预览版记录的是有限样本证据，不是全部版本、全部历史或未来应用的兼容保证。真实材料、截图、数据库和备份不随发布物提供。历史实机回执不是对本候选版每次改动的重新认证；当前候选还需按目标环境复测受影响部分。

旧私有结构检查器仅接受workspace-write，遇App规范化后的managed而失败。后续只读检查确认managed的文件系统/网络为restricted；私有检查器增加受限managed识别，不代表Skill修改或放宽权限。续聊投递回执也不能误判为历史工具配对失败。文件点击原生对照尚未完成，不为试错补造client_id或provider id。

## 其他兼容性及历史诊断

- Python 3.11加临时zstandard 0.25.0实际解压合成与本机压缩来源通过；compression.zstd和系统zstd分支有模拟测试，未在实际Python 3.14或系统zstd命令上完成同等实测。未压缩来源不需要可选依赖。
- Windows合成回归覆盖旧Codex事件、压缩路径、归档、根别名、子目录cwd、二进制旁车、重复目标、原生文件头和损失分类；当前21组测试不是21种平台的验收。
- 早期MAC-003是在先前修正后的同一Codex会话上一次续聊保持绑定，实际resume/turn-start参数未取得。MAC-X2后续样本也不能证明cwd漂移根因已修复或所有新导入都会稳定。始终执行[绑定前后独立核对](CODEX_PROJECT_BINDING.md)。

## 仍待验收／已知限制

- Mac历史含高权限字段、多账号/多org登记、上层目录信任继承；Mac作为Claude原样平移来源的真实符号链接根。
- Mac目标模型的附件访问、未覆盖图片/文件引用、扩展与分支；Codex原生文件点击的对照。
- 根外Codex冷存档、无可识别可见消息的来源不被当作完整迁移成功；项目pack的skipped必须逐项检查。
- 跨Agent隐含推理、加密压缩和harness注入不恢复；Claude原样正文旧绝对路径不改。长会话摘要可能弱化早期主题，完整归档不等于完整上下文。
- Linux原生加载、其他Agent适配器、后续应用版本和当前候选在Mac的全面回归仍未覆盖。
